# IK-01：最小输入类型隔离参考

版本：1；状态：按需试点，非黄金样例；不是项目交付模板。规则归口 [ui15.3.1](../../../standards/ui-and-components.md#s-15)，几何/证据归 [quality29.11～29.13](../../../standards/quality-and-evidence.md#s-29)。本例不含商城业务，不强制引入框架或网络依赖。

双击 [input-kit.html](input-kit.html) 可查看。只演示同宿主文本输入、原生 radio/checkbox 及默认/选中/焦点/禁用/错误/长标签，提供移动/桌面密度切换、原生表单提交/重置；不会持久化或调用接口。不演示完整评审壳层、设备外框、所有输入类型或项目业务。

- [profile.json](profile.json)：本例令牌/密度、局部尺寸、组件与模式映射。继承已批准灰度及热区；16px 选择图形和 288/680px 测试宿主只是本例夹具，不是新通用尺寸。
- [scenario.md](scenario.md)：固定预期、真实浏览器待执行步骤及项目集成边界。
- [baseline.json](baseline.json)：规则/模式/令牌版本、模块及样例输入哈希；维护稿未提交时以实际字节为准。
- [validation.json](validation.json)：实际检查与未验证范围；不能从参考条款批准推断浏览器通过。

静态及纯逻辑检查：`python tools/check_input_reference.py`。它可发现本例的脚本语法、ID/label、外部依赖、令牌和粗粒度选择器污染；不能证明浏览器计算几何、真实点击、焦点、滚动或所有 CSS 级联正确。浏览器/项目集成按 scenario 独立执行；项目换宿主、样式或输入类型后，原通过不继承。

需要时按 `input-kit` 显式打包；默认阶段不读取代码。项目可以实现等价控件，须保持语义/键盘/禁用/错误和标签操作，不把样例全部复制为所有项目组件库。
