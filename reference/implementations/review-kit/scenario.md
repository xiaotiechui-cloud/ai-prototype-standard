# 通用局部样例输入 RK-01

这是用于复现规范机制的小型测试需求，不是商城 PRD，也不是完整项目交付。

- 用移动双栏评审外壳展示“资料记录”表单，单栏时说明回归页面流。展示业务画布实测尺寸；组件选择和描边局部更新，保留未保存的行内备注与滚动。
- 页级注册表包含行内备注、记录列表和仅编辑时展示的组件；选择未展示组件仍能阅读完整十节。
- 两条同名、不同稳定 ID 的记录；编辑第二条只更新第二条。指定失效 ID 时展示错误，不退回其他记录。
- 编辑层在业务画布内，子选择器关闭保留父草稿；脏退出提示放弃/继续。保存失败保留，成功更新记录、版本及执行次数，关闭并恢复入口。
- 图示在评审视口打开，显示构建期生成的灰度 SVG；百分比真实改变尺寸，适应宽度可手动切回原尺寸滚动。关闭保留业务上下文。
- 一切仅内存；刷新重置。样例不实现完整 Markdown 阅读器、九份项目文档、文件上传、异步请求或权限系统，不声称完整符合全套标准。

预期行为是本输入和已确认规则的组合。代码仍须按 [样例说明](README.md) 补真实浏览器验证，不能因放在参考目录就当成已验收黄金产物。
