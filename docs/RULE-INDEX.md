# 稳定规则编号索引

状态：用户确认的模块化维护稿；规则基线仍为 V3.0，当前语义修订尚未正式发布。

## 编号约定

- 跨模块引用的规范规则使用永久 ID，形式为 `STD-{领域}-{序号}`；编号不依赖标题、行号或文件路径。
- 每条规则在唯一权威章节放置 `RULE-ID` 标记；本表记录其解释、权威位置与维护边界。
- 文件拆分、章节改名或移动时保留 ID，只更新权威位置；规则废止时保留 ID 并标记废止，不得复用。
- 新增 ID 只追加序号。普通局部要求仍使用原章号/小节号定位，避免给每个段落增加无意义编号。
- 快速摘要、检查清单和模板引用 ID 或权威章节，不复制规则正文；具体项目检查的操作步骤仍保留在其执行章节。

## 自动核验

`python tools/maintain.py verify` 检查 ID 在本表唯一，并且每个 ID 在表中声明的权威文件内恰有一个标记。检查只证明索引与标记一致，不证明规则内容无冲突或项目已通过交付验证。
