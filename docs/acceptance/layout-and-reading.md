# 几何、滚动与阅读验收

状态与证据格式见 [入口](README.md)。尺寸、热区、字号采用 [ui 7～9](../../standards/ui-and-components.md#s-7) 的权威默认与已确认项目例外，不在此维护第二张尺寸表。

| ID | 前置与实际操作 | 可判定结果 | 应留证据 |
| --- | --- | --- | --- |
| LAY-01 | 项目目标桌面视口下记录外壳/画布/内部宽度；保持窗口不变，调整承载容器 | 实测与标注一致，随容器更新；不重建业务输入，桌面主列表要求仍满足 | 三种宽度、视口、截图、标注更新 |
| LAY-02 | 最长页面/面板在常规与矮视口滚至末尾 | 正文末端、关闭与主动作可达；没有不可滚的裁切区 | 滚动容器、末端截图 |
| LAY-03 | 测量并点击主次按钮、图标、协议整行和弹层边缘 | 实际热区符合对应端要求，图标尺寸与可点击范围分开记录 | 计算尺寸、边缘点击结果 |
| LAY-04 | 双栏分别在画布、说明和区外滚动；切单栏再试键盘与触控 | 说明只有一个主要滚动链、选择器易达；单栏取消限高/吸顶；全文可达 | 各容器 scrollTop 前后、布局截图 |
| LAY-05 | 打开宽说明表、长字段路径、一行一点的基本信息 | 字号遵循 ui 7.2；换行可辨，不逐字挤排或缺列；必要时局部横滚 | 完整表头、计算字号、局部滚动结果 |
| LAY-06 | 窄屏阅读文档，操作目录、跨文档链接、历史、下载 | 正文/目录/目标同步，返回恢复位置，目录有替代入口；下载等于源 MD | 跳转目标、下载哈希、阅读位置 |
| LAY-07 | 同页放业务提示、字段帮助和设计注释（可使用相同 hint 样式） | 只迁出显式评审注释，业务提示/帮助保留含义；归属准确 | 语义标记、迁移前后文案与归属 |
| LAY-08 | 在业务画布内用滚轮、触控/触控模拟、键盘及程序化滚动到首尾；查看滚动滑块 | 内容首尾均可达；默认隐藏装饰性内部滑块，不锁页面滚动、不裁内容；登记的可见性例外符合契约 | 宿主与滚动区 ID、输入方式、滑块状态、首尾位置、例外依据 |
| LAY-09 | 按 web 第 11.7 节，在 1920/1440/1280/1024 CSS px 代表视口（或项目登记的目标范围）分别检查评审外壳和业务画布 | 主任务区不被工具区挤压/遮挡；分栏、网格、导航和说明依容器调整；表格内容可读，记录实测画布宽度 | 视口与容器尺寸、截图、主任务区宽度、换列及溢出结果 |
| LAY-10 | 按 ui 7.4 和项目快照，在默认/加载/空/错误/长内容下测量移动外框、内部业务区和正文；核对边线/圆角/内边距/听筒，并滚至主操作 | 外框固定、居中和自然留白符合约定；正文独立滚动，样式令牌匹配；不混淆内外尺寸，不遮挡操作 | 各层矩形、各边计算样式、听筒尺寸/颜色、视口/缩放、滚动前后截图及覆盖依据 |
| LAY-11 | 依 ui 7.4.1 测量内容宽预算、最小可读宽，改变容器宽并使用长内容/完整动作 | 分栏/网格按合同收拢、角色顺序正确，不套商城断点或裁切关键内容 | 预算、容器/列矩形、收拢前后截图及合同来源 |
| LAY-12 | 按相同变体比较标签/动作对齐、语义间距、字体/边框/圆角、媒体加载前后 | 匹配 ui 7 和批准覆盖；长标签/错误自然扩展，媒体几何稳定 | 计算样式、目标/实际、夹具和变体/覆盖来源 |
| LAY-13 | 各适用端/密度下点击图形边缘和热区，切错误/处理中/长文/文字缩放 | 热区不重叠、尺寸满足对应端，固定高度不裁内容，主操作可达 | 图形/热区矩形、真实命中、状态与缩放 |
