# AI交付自测操作矩阵

权威：[quality29.9～29.14](../../standards/quality-and-evidence.md#s-29)的`STD-QA-001`；准出按`STD-GATE-001`。本文件是可复用操作方法，不是已执行记录；每行初始未验证，映射项目TC/CHK后执行。

| 行 | 操作与夹具 | 应保存的证据 |
| --- | --- | --- |
| SELF-01 | 实现前读PRD/规范，固定布局/行为预期；声明实际工具能力 | 来源、模块/契约哈希、预期计划、能力缺口 |
| SELF-02 | 注册表与真实DOM双向列业务/评审/原生入口，分别点按钮和下拉；按适用状态检查实际组件 | 分开记录注册、渲染、可见、可操作与文档绑定；隐藏补锚点不算真实覆盖；入口/参数/处理/结果、禁用原因、适用与缺失分母 |
| SELF-03 | 各端独立从主入口执行P0链路及共享能力的成功/失败/返回，按ACT-01检查可见入口与实际处理动作；页面状态预设仅造初态，登录/实名/手机号等条件按需组合 | 入口组件、实际处理动作、起始/最终端/账号/对象、回执与控制台分别记录；获准跨端按契约；快捷条件、处理函数存在或直接调用不替代业务入口 |
| SELF-04 | 用B与A两条不同记录执行详情/复制/编辑；成功/取消/失败/未知/重复/权限按风险覆盖 | 前后数据、保持项、目标一致性、模拟边界 |
| SELF-05 | 配置改值/合法清空，按模块直接保存或草稿/发布契约测失败/成功，去各消费者核对 | 版本、消费者实际值、历史快照不变、审计真实before/after |
| SELF-06 | 慢A快B；旧A未回→重置/关闭→新B→A返回；另测切页/端/账号 | 不因可变引用或身份重用误认；当前数据/loading/提示/导航不被A改写 |
| SELF-07 | 每类布局/弹层加入长内容、窄/矮视口，滚到末尾并点击主操作/关闭 | 视口/缩放/实际画布、截图/矩形/命中、父子层/焦点/滚动 |
| SELF-08 | 检查灰度、中文、业务滑块、菜单/单行导航；阅读器全部文档及图示 | 具体状态/入口证据，不能以打开面板代替切换/下载/缩放 |
| SELF-09 | 修缺陷、同步MD、重建，复测失败项及共用能力/各端/上下游 | 原失败、修改、复测批次、被测新哈希与剩余缺口 |
| SELF-10 | 固定主文件再封存外部结果，核对07/08汇总和实际文件；将输入文件字节摘要与各断言/截图对应 | 运行ID、输入/计划/产物SHA-256、断言/截图映射、环境和证据文件存在；运行时DOM指纹/长度与计数独立标名，不能当文件SHA；无内嵌哈希循环 |
| SELF-11 | 对有人工展示顺序的后台列表拖拽、保存并重载；再用键盘/触屏替代操作；另测查询排序 | 把手、目标位置、保存反馈/持久化及失败恢复正确；查询排序字段和结果正确，互不混淆 |
| SELF-12 | 按quality29.13分开查已批准含义、最终内外文档/下载源/注册同源、真实入口行为 | 三类各自方法/结果/限制，规范化比较留原哈希；参考反例与历史通过不继承 |

几何、层栈和具体动作使用 [矩阵入口](README.md) 中相应方法；内容/表单/数据/查询按 [模式入口](../patterns/README.md) 选择。真实浏览器不具备时保留L4/L5未验证，可交评审稿，不宣称验收通过。

结果与前次失败进入08唯一实际记录，07引用同批次；TC、入口覆盖和检查结论分别统计。没有执行的行不填实际结果/通过日期，不为展示通过率缩减分母。

按quality29.10/29.13写明统计单位与分母：若总状态已是各页状态组合之和，只乘实际适用模拟/环境组合，不再乘页数；展示断言、提交闭环和风险分支分别计覆盖。提供方/历史结果标来源、输入摘要、环境、覆盖边界及是否本轮复跑；未强绑定最终字节的证据保留缺口，不删除或伪造关联，也不继承为本轮通过。
