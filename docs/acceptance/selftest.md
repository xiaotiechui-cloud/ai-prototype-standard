# AI交付自测操作矩阵

权威：[quality29.9～29.14](../../standards/quality-and-evidence.md#s-29)的`STD-QA-001`；准出按`STD-GATE-001`。本文件是可复用操作方法，不是已执行记录；每行初始未验证，映射项目TC/CHK后执行。

| 行 | 操作与夹具 | 应保存的证据 |
| --- | --- | --- |
| SELF-01 | 实现前读PRD/规范，固定布局/行为预期；声明实际工具能力 | 来源、模块/契约哈希、预期计划、能力缺口 |
| SELF-02 | 注册表与真实DOM双向列业务/评审/原生入口，分别点按钮和下拉 | 入口/参数/处理/结果；禁用原因；适用与缺失分母 |
| SELF-03 | 各端独立从主入口执行P0链路；状态预设仅造初态 | 真实步骤、对象ID、实际结果和控制台，端分别记录 |
| SELF-04 | 用B与A两条不同记录执行详情/复制/编辑；成功/取消/失败/未知/重复/权限按风险覆盖 | 前后数据、保持项、目标一致性、模拟边界 |
| SELF-05 | 配置改值/合法清空，草稿保存/发布失败/成功，去各消费者核对 | 版本、消费者实际值、历史快照不变、审计真实before/after |
| SELF-06 | 慢A快B、切页/端、关闭、重置后让旧回调返回 | 当前数据/loading/导航未被旧回调改写 |
| SELF-07 | 每类布局/弹层加入长内容、窄/矮视口，滚到末尾并点击主操作/关闭 | 视口/缩放/实际画布、截图/矩形/命中、父子层/焦点/滚动 |
| SELF-08 | 检查灰度、中文、业务滑块、菜单/单行导航；阅读器全部文档及图示 | 具体状态/入口证据，不能以打开面板代替切换/下载/缩放 |
| SELF-09 | 修缺陷、同步MD、重建，复测失败项及共用能力/各端/上下游 | 原失败、修改、复测批次、被测新哈希与剩余缺口 |
| SELF-10 | 固定主文件再封存外部结果，核对07/08汇总和实际文件 | 运行ID、计划/产物哈希、证据文件存在；无内嵌哈希循环 |

几何、层栈和具体动作使用 [矩阵入口](README.md) 中相应方法；内容/表单/数据/查询按 [模式入口](../patterns/README.md) 选择。真实浏览器不具备时保留L4/L5未验证，可交评审稿，不宣称验收通过。

结果与前次失败进入08唯一实际记录，07引用同批次；TC、入口覆盖和检查结论分别统计。没有执行的行不填实际结果/通过日期，不为展示通过率缩减分母。
