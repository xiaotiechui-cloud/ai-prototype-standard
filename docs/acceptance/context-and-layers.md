# 业务上下文、组件与层栈验收

状态与记录格式见 [入口](README.md)。权威：[ui 8/9](../../standards/ui-and-components.md#s-8) 的 `STD-RV-001`，以及 [runtime 13.8](../../standards/runtime-and-build.md#s-13) 的 `STD-RT-001`。

| ID | 前置与实际操作 | 可判定结果 | 应留证据 |
| --- | --- | --- | --- |
| CTX-01 | 输入未提交值、选择记录、滚至中段，再切组件/描边 | 仅工具区域变化；业务页/状态、会话、ID、草稿、数据版本、滚动一致 | 相同字段的前后快照；描边几何对照 |
| CTX-02 | 保持上述上下文，打开关闭图示，再阅读/切文档/返回 | 业务快照保持；焦点回实际工具入口；工具不写业务数据 | 快照、焦点目标 |
| CTX-03 | 默认态选择只在其他状态展示的组件，再进入适用态，操作实际组件 | 分开登记注册、实际渲染、可见性、可操作性与文档绑定；默认标未展示，适用后能定位并操作；隐藏补锚点不能计作真实组件覆盖 | 注册表、适用状态、实际DOM/可见性/操作结果、两态选项与十节 |
| CTX-04 | 父编辑层输入草稿，开子选择器，滚动并按一次 Esc | 只关子层，父草稿不变；背景继续锁定；焦点回父层入口 | 层栈、草稿、背景/正文位置、焦点 |
| CTX-05 | 有脏数据时分别用按钮/Esc/允许的遮罩退出；选继续，再选放弃 | 各出口同一生命周期；继续不丢值，放弃后才清理；纯查看直接关；PRD 覆盖可追溯 | 出口×选择记录、草稿、决策引用 |
| CTX-06 | 顶层不可关闭时按 Esc/遮罩，再正常结束全部层 | 顶层拦截，不关闭下层；全部相关模态结束后才还原原 overflow、位置与焦点 | 层数、锁计数、还原前后值 |
| CTX-07 | 切页/端/状态与重置；让旧异步响应稍后到达 | 不残留旧组件/瞬态或旧回调写入；重置回声明 fixture | 请求版本、重置范围与初始快照 |
| CTX-08 | 对照共享组件的两个页面实例，并检查一个废弃实例 | 合成十节含具体来源/动作/异常/返回；无失效引用或通用句冒充，废弃 ID 不复用 | 合成结果、覆盖与引用检查 |
| CTX-09 | 在移动设备壳、桌面业务画布、后台工作区分别打开居中弹窗/抽屉/底部面板 | 定位和遮罩边界相对已声明宿主；居中弹窗在宿主内居中、边缘面板贴宿主；除声明全屏流程外不覆盖整个文档或评审工具区 | 宿主/弹层 ID、边界矩形、中心偏差、遮罩边界及全屏例外契约 |
| CTX-10 | 逐一过滤不同角色菜单权限并尝试菜单入口、直链和敏感操作 | 零可见子项的分组隐藏；直链及敏感操作仍独立鉴权并反馈 NO_PERM | 角色、可见菜单、直链结果、操作鉴权结果 |
| CTX-11 | 按runtime13.5分别同对象重开、换B、目标失效、取消/返回、成功后重入和切账号；对验证码/实名/协议/授权等已有资格，更换其适用目标或版本 | 各自保留/清理策略成立；显式目标失效报错不换记录；查询/选择/滚动/焦点分别核对；资格按适用对象/账号/来源/版本失效或重验，保留输入不自动保留过期资格 | 端/账号/稳定ID/来源、资格适用范围与版本、策略引用、前后现场 |
| CTX-12 | 旧A未回时重置/离页回同页或关闭重开，再发B，让A最后返回；另测同页乱序，以及资格重发/目标或账号切换后的旧响应 | 按runtime13.6隔离请求生命周期，A不改B的数据/loading/提示/导航或资格；不因版本归零或可变引用误认 | 固定请求身份、生命周期、资格适用上下文、回调时序及各断言前后值 |

业务恢复策略及异步身份分别以[runtime13.5/13.6](../../standards/runtime-and-build.md#s-13)为权威；不把评审工具快照要求直接套成所有业务表单永久保留。

资格可共享范围按已批准契约，不一律要求跨端重验；模拟验证码无需真实短信服务，时效、重试次数等由项目DEC确定。离线资格夹具不证明真实服务安全性。组件覆盖按[quality26.4/29.10](../../standards/quality-and-evidence.md#s-26)核对，条件组件只在适用状态要求出现。

几何位置与焦点须在真实浏览器补验，纯数据快照不能证明遮挡、焦点循环或滚动锁已生效。
