# 业务上下文、组件与层栈验收

状态与记录格式见 [入口](README.md)。权威：[ui 8/9](../../standards/ui-and-components.md#s-8) 的 `STD-RV-001`，以及 [runtime 13.8](../../standards/runtime-and-build.md#s-13) 的 `STD-RT-001`。

| ID | 前置与实际操作 | 可判定结果 | 应留证据 |
| --- | --- | --- | --- |
| CTX-01 | 输入未提交值、选择记录、滚至中段，再切组件/描边 | 仅工具区域变化；业务页/状态、会话、ID、草稿、数据版本、滚动一致 | 相同字段的前后快照；描边几何对照 |
| CTX-02 | 保持上述上下文，打开关闭图示，再阅读/切文档/返回 | 业务快照保持；焦点回实际工具入口；工具不写业务数据 | 快照、焦点目标 |
| CTX-03 | 默认态选择只在其他状态展示的组件，再进入适用态 | 页面注册表仍列该实例；默认标未展示，适用后能定位；共享覆盖解析完整 | 注册表、两态选项与十节 |
| CTX-04 | 父编辑层输入草稿，开子选择器，滚动并按一次 Esc | 只关子层，父草稿不变；背景继续锁定；焦点回父层入口 | 层栈、草稿、背景/正文位置、焦点 |
| CTX-05 | 有脏数据时分别用按钮/Esc/允许的遮罩退出；选继续，再选放弃 | 各出口同一生命周期；继续不丢值，放弃后才清理；纯查看直接关；PRD 覆盖可追溯 | 出口×选择记录、草稿、决策引用 |
| CTX-06 | 顶层不可关闭时按 Esc/遮罩，再正常结束全部层 | 顶层拦截，不关闭下层；全部相关模态结束后才还原原 overflow、位置与焦点 | 层数、锁计数、还原前后值 |
| CTX-07 | 切页/端/状态与重置；让旧异步响应稍后到达 | 不残留旧组件/瞬态或旧回调写入；重置回声明 fixture | 请求版本、重置范围与初始快照 |
| CTX-08 | 对照共享组件的两个页面实例，并检查一个废弃实例 | 合成十节含具体来源/动作/异常/返回；无失效引用或通用句冒充，废弃 ID 不复用 | 合成结果、覆盖与引用检查 |

几何位置与焦点须在真实浏览器补验，纯数据快照不能证明遮挡、焦点循环或滚动锁已生效。
