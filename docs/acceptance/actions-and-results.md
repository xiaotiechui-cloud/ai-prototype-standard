# 动作闭环、身份与图示验收

## 跨组件连续路径（待执行）

依据 ui 14.4.1/15.5/15.6、runtime 13.5～13.8 和 quality 29.9～29.14，从固定输入定义预期并映射 07；08 记录环境、步骤、每步对象/查询/草稿/正式值、数据变化与不变、焦点/滚动和实际证据。以下只在能力适用时执行，不新增业务：

| 路径 | 连续操作与断言 |
| --- | --- |
| J-01 查询与对象 | 查询→排序/分页→打开 B→返回；查询、页码、滚动按合同恢复，B 失效不能打开 A |
| J-02 父子编辑 | 父编辑→子层取消/确认→保存失败→重试；父草稿/正式值边界正确，不重复提交 |
| J-03 拖拽与取消 | 手柄排序→编辑被移动记录→取消；对象按稳定 ID，顺序按草稿/即时合同恢复 |
| J-04 迟到响应 | 慢 A→新 B→A 迟到；A 不改 B 数据/loading/反馈；若禁止并发，可用关闭重开/重置构造 |
| J-05 外部未知 | 唤起→未知→关闭展示→返回查询；关闭不推定外部取消或成功，查询仍对应原对象 |
| J-06 几何与状态 | 各适用端/变体连续切加载/长文/错误/结果并开关层；几何合同、热区和末端操作可达，CSS 不替代实测 |

代表路径不替代完整入口与状态分母；复用证据须列路径差异和未测范围，不每一步重置为预期结果。

状态与记录格式见 [入口](README.md)。权威：[runtime 13.3](../../standards/runtime-and-build.md#s-13) 的 `STD-ACT-001`、[admin 12.6/12.9](../../standards/profiles/admin.md#s-12)、[reader 18](../../standards/diagrams-and-reader.md#s-18)。按项目已有能力选择，不扩大业务范围。
