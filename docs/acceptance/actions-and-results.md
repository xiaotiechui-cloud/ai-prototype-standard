# 动作闭环、身份与图示验收

状态与记录格式见 [入口](README.md)。权威：[runtime 13.3](../../standards/runtime-and-build.md#s-13) 的 `STD-ACT-001`、[admin 12.6/12.9](../../standards/profiles/admin.md#s-12)、[reader 18](../../standards/diagrams-and-reader.md#s-18)。按项目已有能力选择，不扩大业务范围。

| ID | 前置与实际操作 | 可判定结果 | 应留证据 |
| --- | --- | --- | --- |
| ACT-01 | 从真实入口开确认层，取消一轮，再打开并确认；双击确认 | 打开/取消不写数据；确认执行一次，ID/参数一致；分发与重放无未定义处理函数 | 数据前后、执行次数、对象参数、控制台 |
| ACT-02 | 打开前移除目标，或确认期间使其失效；另试同名不同 ID | 明确错误，不替换第一条/其他记录；新增仍使用独立空草稿 | 目标 ID、错误态、其他记录未变 |
| ACT-03 | 合法/缺必填/失败/未知结果分别保存，再开同一记录 | 成功行为符合提交/就地契约；失败留草稿，未知不误报；相关列表/详情同源 | 各分支数据、界面、重开结果 |
| ACT-04 | 直接及 label 点击 checkbox/radio，中文组合输入后提交 | 默认输入行为可用；输入不重建导致丢值/焦点，校验可见 | 真实点击、输入、焦点与校验 |
| ACT-05 | 鼠标/键盘开文件选择，取消，再选同一文件；排序/删除/预览后保存重开 | 原生入口可达，取消无假成功，预览跟稳定 ID；内存演示边界明确 | 文件选择路径、素材 ID、重开结果 |
| ACT-06 | 同图选择 50%/100%/200%（如提供），再切适应宽度 | 实际 SVG 宽度成比例；宽图原尺寸可滚或有拆图，文字与边界可读 | 实测宽度、原尺寸边界截图 |
| ACT-07 | 流程、状态机、长时序逐条对照节点/迁移/消息表 | 角色、条件、未知/失败/取消/恢复可追溯；概览不丢关键分支，灰度下可辨 | 图号与表行映射、缺口 |
| ACT-08 | 改关联配置后查列表/详情/其他端；再试取消、失败、迟到响应和重置 | 同一事实一致，无部分写入或跨记录串写；回到声明 fixture | 稳定 ID、各入口值、版本与重置快照 |
| ACT-09 | 对重建产物阻断网络后直接打开并跑代表性主链 | 声明的离线能力成立，操作到结果；语法/静态/浏览器证据分开 | 产物哈希、网络与新鲜控制台记录、操作结果 |
| ACT-10 | 按business24.5构造合法空、0/false、缺字段、未完成、失败/未知 | 依字段契约显示/拒绝/保留，不隐式回填演示结果 | 字段契约、输入值、结果集与界面状态 |
| ACT-11 | 后台改B的非等差规格价格；重排/改名后建新单、查看旧单 | 按core3.4生产消费贯通、子项身份稳定；旧快照不随目录变化 | 唯一路径、各端实际值、新旧对象快照 |
| ACT-12 | 按模块生效契约保存/发布，分别取消、失败、成功及重开 | 依admin12.11生效；草稿不提前消费，直接保存不强增发布；部分结果按对象可辨 | 生效版本、前台值、草稿、对象结果与重试边界 |
| ACT-13 | 有权打开B后撤权/切账号/改目标状态，再确认提交；另做一次合法角色变更 | 按admin12.13执行前重验，拒绝不写业务数据；审计before取不可变旧值，after为真实结果 | 权限/状态前后、对象ID、业务及审计记录 |
| ACT-14 | 从纯查看、导出、明确开始、组合处理、完成入口分别操作并取消/确认 | 按runtime13.3的实际契约核对写入/产生物；组合副作用明示，导出不冒充交付完成 | 动作契约、范围/次数、文件或模拟任务、状态与回执 |
| ACT-15 | 复制B，测试成功、Promise拒绝、API缺失、兼容返回false及异常；下载/外部唤起按能力补测 | 按runtime13.3基于可观察结果反馈，未确认外部完成不报已完成；有手动/恢复路径 | 能力/API结果、目标内容、反馈与限制 |
| ACT-16 | 从真实控件/导入入口提交 `"0"`、`"false"`、合法零、空白、非法/越界数值及必填清空 | 按字段契约解析、校验并反馈；非法值不静默默认或保留旧值报成功，必填清空保留输入 | 原值、契约、解析模型、错误反馈、保存前后值 |
| ACT-17 | 建立父对象含A/B，分别完成、失败、取消、重复回执及空批次；另测独立封批 | 父状态按声明聚合；单成员不提前全完成，成员结果可定位且终态不重复推进；封批与交付完成分开 | 成员/父状态前后、回执次数、封批事实与TC |

ACT-10、ACT-16的字段判定权威为[business24.5](../../standards/deliverables-business.md#s-24)，ACT-11、ACT-17为[core3.4](../../standards/core.md#s-3)；其余分别引用[runtime13.3](../../standards/runtime-and-build.md#s-13)、[admin12.11/12.13](../../standards/profiles/admin.md#s-12)。本表按实际能力映射项目用例，初始未验证。

历史回归反例：试跑版确认调用了不存在的 `handleAction`，缩放写入了没有消费方的 `--dgzoom`；语法通过未发现它们。新项目检查真实连通与呈现，不仅搜索这两个旧名称。详见 [原差异评审](../reviews/2026-10-20-steam/01_详细差异分析.md)。
