# 按需验收矩阵

这些文件把活动规范转成操作步骤，不是第二套权威条款，也不是已执行记录。默认阶段包不包含正文；按本次改动选择，结果统一回填项目 08。

| 触发条件 | 读取 | 权威依据 |
| --- | --- | --- |
| 生成交付、自测计划、能力缺口或缺陷修复回归 | [AI自测](selftest.md) | STD-QA-001；STD-GATE-001 |
| 改尺寸、排版、响应式或说明滚动 | [几何与阅读](layout-and-reading.md) | ui 7、8.4、9.3；reader 19 |
| 改组件选择、描边、工具、父子弹层或资格适用上下文 | [上下文与层栈](context-and-layers.md) | STD-RV-001、STD-RT-001；ui 8.5/9.5；runtime 13.5/13.6 |
| 改跨端共享入口、确认、保存、字段解码、批次聚合、记录、上传、图示或数据联动 | [动作与结果](actions-and-results.md) | STD-ACT-001；runtime 13.5；business 24.5；core 3.3/3.4；admin 12.6；reader 18 |

固定 PRD 哈希、规范 commit/模块哈希、人工覆盖决策、产物哈希及初始 fixture；运行记录增加浏览器版本、视口宽高、浏览器缩放、实际画布尺寸。本文中的 ID 是复用检查模板编号，项目应映射到自己的 TC/CHK，不替代唯一执行编号。

跨端可见入口、资格范围、组合字段/新增草稿、聚合边界/重导出、展示与结果、证据身份与分母的检查已合并到现有矩阵行；仍按原权威规则和项目例外执行。输入文件SHA、运行时摘要及统计数分别标明；原型分析报告不随默认阶段加载。

每行初始结论为**未验证**，不适用须写依据。实际结果和证据执行后填写；失败保留，复测另记批次。静态、语法、纯逻辑、浏览器操作及截图分别记录，不相互继承通过。

```text
TC/CHK / 矩阵行：
输入与被测产物哈希 / 规范快照：
环境与初始数据：
实际操作与对象 ID：
实际结果 / 证据位置：
结论：通过 / 失败 / 未验证 / 不适用
未验证范围 / 缺陷 / 复测批次：
```

可配合 [局部参考实现](../../reference/implementations/review-kit/README.md) 理解执行方式；参考实现没有替代项目回归的效力。

涉及具体能力时按 [模式入口](../patterns/README.md) 补读，适用性/契约由项目模型记录。矩阵正文通过support显式加载，缺省包不携带全部步骤；权威条款仍按阶段读取。
