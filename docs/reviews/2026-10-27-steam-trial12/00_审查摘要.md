# 试跑12.0与最终版比较：摘要与续读入口

日期：2026-10-27。状态：分析完成，C1～C5 已批准并落实；C6 保留为按需试点。未修改原型及项目交付物，未提交或推送。

结论：现行 UI Profile、组件注册与固定设备尺寸的方向仍可保留，但注册齐全不等于结构、样式、业务行为已经执行。试跑12存在可定位的执行缺陷和自测漏检；不能将其全部归因为规范缺项，也不支持据此回滚整套规范。

## 范围与事实

- 试跑：50页、271个页面状态、224个组件实例、66个共享定义、20张图、9份MD。最终版：41页、152个页面状态、192个组件文档条目、35张注册图、9份MD。组件计数口径不同，两版PRD基线也不同，不据数量判断完整度。
- 本轮复核25个交付文件的哈希，最终版哈希与已有清单一致；9份外部MD与HTML内嵌版本的规范化文本一致。
- 生成方报告手机外框320×640、业务区288×592，布局截图显示灰度与多端壳层已经落实；这属于生成方测量/截图证据。本轮没有独立测得全部几何或完成浏览器验收。
- 本地file协议被浏览器安全策略拒绝，未绕过。以下行为结论来自源码；截图仅证明被拍摄场景。
