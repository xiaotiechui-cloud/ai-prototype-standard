# 18个可按需加载的组件与交互模式：待审稿

> 后续状态：用户已批准分层维护方案；以下候选已按原章去重，能力细节见[按需模式入口](../../patterns/README.md)。不将全文逐字提升为通用强制规则，当前归口见[确认与落实](../2026-10-20-cross-model-selftest/04_确认与落实.md)。

这些模式来自 [全域分析X01～X30](06_全域细节对比与归纳.md)。目的是把“看起来不一样”变成生成AI能执行、验收AI能判断的契约。P01～P18仅是本轮评审编号，不是新STD或PAT正式编号；本文件不在默认生成输入中。

不是把18个模式一次塞给所有任务。确认后先去重：已有强制要求补充其原归口的验收断言；能力细节拆成按需辅助文件；商城特定的页面顺序、数值与支付路径保留为项目覆盖。下面的新增建议均为候选，不把“应该如此”冒充用户已批准的新规范。

## 共同的组件细节契约

建议在现有统一模型及03组件十节中使用以下字段，复用已有字段，不额外强制产生第11份主交付物。

| 字段 | 具体需要写到什么程度 |
| --- | --- |
| 职责与适用条件 | 解决什么任务；哪些项目/端使用；不适用时写理由 |
| 实例与父子关系 | 稳定ID、所属页/父层、共享定义与本实例覆盖 |
| 布局 | 区块顺序、分栏、默认/上限尺寸、主操作位置、窄/矮场景、滚动归属 |
| 数据与字段 | 生产方+字段路径、可编辑/派生/只读、单位/格式/空值/敏感性 |
| 状态 | 业务事实、组件瞬态、展示标签分别定义，说明谁驱动谁 |
| 入口与动作 | 点哪个真实控件、携带哪个对象、前置条件、禁用依据 |
| 变化与副作用 | 哪些数据提交、哪些仅改草稿、是否创建订单/批次/版本 |
| 反馈 | 哪层显示、等待/成功/失败/未知、是否自动消失及后续可查记录 |
| 退出与恢复 | 关闭/Esc/遮罩/返回、父层/焦点/草稿/滚动、外部返回重验 |
| 并发与失效 | 重复提交、迟到回调、对象被删/下架、会话/权限变化 |
| 追溯 | PRD/用户决策/项目覆盖、接口/图节点/埋点/用例ID |
| 验收 | 夹具、真实入口步骤、可观察断言、实际证据与未执行项 |

示例：“购买按钮可用”不够具体；应写成“当前商品可售、所选规格有效、协议已确认且无提交中任务时可提交；手机号不满足时打开绑定子层，父层保留规格/链接/支付选择；返回后重新获取绑定状态”。

## P01 页面任务与导航结构

适用：首页、账号中心、后台菜单及具有重复入口的页面。来源X01/X02/X06。

候选条款：生成前给每个页面声明主任务、信息分组和入口归属。一级导航、页内快捷入口、流程返回入口分别登记，新增重复入口需有场景依据。分组顺序和主操作位置依据已批准项目契约；页面加载/空/失败状态不应无故隐藏仍可用的全局导航。

账号中心按账号、待办、资格、服务等项目需要分组；待办角标须明确集合和清零条件，累计总量不能无说明地伪装成待处理。动态平台/账号来自当前身份，不硬编码为参考样例用户。

验收：访客、已登录、资格未知及有待办四种夹具，逐入口确认目的页/过滤条件；同一目的在首页出现多次时核对理由。商城两个底栏、四组个人中心属于项目覆盖，其他项目可不同。

归口：ui 15.2；客户端10.1/10.7；后台12.2。

## P02 来源、返回与阅读上下文

适用：搜索→详情→返回、订单→客服、文档A→B→返回、外部平台回跳。来源X03/X04/X14/X29。

候选条款：为流程记录`来源页/当前对象ID/已提交条件/草稿/滚动位置/返回目标`，按入口场景定义恢复和清理。新开入口与返回恢复不得仅凭“目标页相同”合并处理。客服从订单进入携带此订单；公共入口不随机附带历史订单。

文档切换前保存当前正文滚动和历史；“返回上一文档”退一步并恢复该文位置，首次进入禁用。目录只滚动正文容器。关闭评审工具保持业务上下文，遵循STD-RV-001。

搜索历史在V2.2和现行client10.2已有要求；涉及搜索且无明确项目覆盖时执行去重、置顶、上限、删除/清空及空态，不因本模式按需加载而变可选。进一步明确存储范围、写入时机和身份切换隔离。默认搜索空输入、返回不回填同样属于已有默认规则；F的历史10条/30字符仅作项目参考数值。来源与本次表述更正见 [规则核对](../2026-10-20-cross-model-selftest/01_V2.2与V3.0规则核对.md)。

验收：从结果第2页中部打开商品再返回；从B订单联系客服；文档A滚中段→B→返回；新开搜索与返回搜索分别断言。归口：runtime13.5/13.7；client10.2/10.7；reader19。

## P03 结果集的空、加载、失败与末页

适用：搜索、推荐、商品列表及其他异步内容区。来源X04/X05。

候选条款：分别表示未发起、首屏加载、成功非空、成功为空、首屏失败、追加中、追加失败、末页。数据数组为空不得自动填默认样例。重试沿用原查询快照并真实触发请求/模拟请求；局部失败保留独立区域及已成功加载的数据。

追加成功保留原列表并按稳定ID去重，末页仅改变继续加载能力和终态提示。只有一页的项目正确禁用翻页即可。推荐失败不清搜索历史，下一页失败不清首屏。

验收：无匹配关键词、推荐失败但有本地历史、第二页失败后重试、末页保留所有已载记录。归口：ui7.5/15.6；runtime13.3；client10.2/10.3。不是新增另一套“假数据可用”标准。

## P04 内容详情与媒体展示

适用：具有媒体、长资料、固定主操作的详情页。来源X06～X08。

候选条款：以项目契约固定媒体/概要/长资料/辅助说明/主操作的分组顺序、两端承载、展开行为与空字段策略。媒体是序列，声明当前项、切换、数量、空/失效、图片/视频占位、比例和选中反馈；支持哪些真实能力需另写清楚。

本次已确认灰度线框仍保留图集/选择/弹层/滚动，通过文字、边框、明暗与符号表达状态。不得以彩色包装或静态图片替代交互。图片不拉伸、长内容不遮主操作、空可选字段按契约隐藏；是否吸顶以实际可用高度判断。

验收：0/1/多媒体、长标题、两档资料都空、长介绍、不可售、矮视口。PC左右结构和280px媒体等放商城契约；不强制所有详情都两栏。归口：client10.4；web11.2/11.4；ui7.4。

## P05 有依赖的表单与重复字段组

适用：购买面板、商品规格编辑、任何动态必填/重复组表单。来源X09/X10/X20。

候选条款：字段声明可编辑/派生/只读、数据路径、显隐及必填依赖；上游值改变时明确下游保留/清除/重验。重复组声明最小/最大项、每项身份、增删入口、校验定位、排序与删除当前项的落点。

使用独立草稿，业务校验通过后按既定提交边界应用；校验失败留在当前层，保留输入并指出出错字段。派生价格/交付方式只读同一已确认规格，不能另建固定价格表。外部资格返回保留表单并重新获取资格；不能因保留选择就跳过重验。

验收：切交付方式使好友链接变为必填；多规格新增/删除最后一项；非法价格；保存失败；取消后重开；后台修改规格后前台选购。多规格是能力选项。归口：ui15.3；runtime13.5；admin12.11；client10.5。

## P06 复合弹层的层级、几何与退出

适用：购买主层+须知/帮助、后台编辑+关联选择、支付层/订单详情。来源X10～X12；原C2-02。

候选条款：每层登记宿主、父层、对象、尺寸、标题/关闭/操作位置、滚动区、背景锁、焦点、取消落点及保留内容；由STD-RT-001统一控制生命周期。打开子层保持父层草稿；一次Esc只处理最上层；未保存关闭遵循项目已确认提示策略。

校验提示不得无声明地替换主表单；成功提交按动作类型关闭或留层，失败保留。反馈必须在当前活动层能看见。关闭支付层不改变支付结果。移动底部面板与PC居中层分别约束几何。

验收：连开两层、取消/叉号/Esc/遮罩逐个验证；长正文和矮视口下标题/主操作可达；测量遮罩宿主与弹层矩形；父层草稿、背景滚动和焦点恢复。归口：runtime13.8/13.10；admin12.9/12.10；web11.4/11.5。

## P07 关联对象选择器

适用：推荐商品、区域、多选关系字段等。来源X20/X21。

候选条款：关联数据量与错误成本适合时，提供可检索候选而非要求用户记ID。候选明确资格、名称/ID、已选反馈、重复策略、单/多选、空/错/无权限及失效项。子层维护临时选择，确定才写父草稿，取消不改变父值。

对已配置后下架/删除的对象，明确保留配置并标失效、自动隐藏或移除的策略；不能悄悄换另一对象。少量稳定编码输入可作为有依据的例外。

验收：选择后取消、确认后再开、重复商品、无候选、候选被下架/删除、检索失败。归口：ui15.3/15.5；admin16.7。商城选择器的具体列与最多数量写项目契约。

## P08 素材管理与排序

适用：图集、广告、带预览的文件/媒体编辑。来源X08/X22。

候选条款：文件选入→校验→临时预览→保存/发布→持久引用→删除，逐步说明能力与状态。素材身份不随数组位置变化；重排仅改顺序，预览仍指向同一素材；删除当前项有确定后继，空序列有恢复入口。拖拽可见且确实写顺序，建议提供按钮/键盘替代。

声明类型/大小/数量、失败反馈、取消选择、临时资源释放、刷新后是否保留；仅保存名称或内存预览不得声称已上传/持久化。灰度线框可使用可识别的媒体占位，不影响排序和预览选择验证。

验收：选错类型、取消文件、拖排后预览、删当前/末项、关闭未保存、保存后重开/刷新。归口：ui15.3/15.6；runtime13.7/13.9；core3.6。

## P09 配置的读写、生效与版本闭环

适用：广告、商品、搜索推荐、客服、协议/模板。来源X09/X14/X23/X24/X28。

候选条款：每项配置登记生产方字段、编辑草稿、保存/发布对象、生效快照、前台消费者路径、过滤/排序/展示上限、空值/失效策略和刷新时机。STD-MODEL-001负责同源，不另立相同权威。

若提供草稿/发布，草稿保存不可改生效快照，发布成功才切换版本，失败保留草稿，历史交易保留成交快照。若是立即保存，文案及可见效果必须符合立即生效。清空合法配置时不能自动回填演示默认值。

协议版本、模板版本与历史订单/通知关联分别定义，查看不等于同意，更新模板不重写历史消息。富文本、回滚、定时发布均为项目能力，不自动要求全部实现。

验收：保存未发布前看前台、发布后APP/WEB对照、停用/重排/清空/失效商品、编辑协议后查旧订单快照、发布失败保留草稿。归口：core3.4；admin12.11；runtime13.3；05接口/数据契约。

## P10 交易、外部结果和幂等恢复

适用：支付、取码、绑定、退款及外部SDK操作。来源X10/X12/X26。

候选条款：请求发起、外部页面返回、服务端受理、最终成功、失败、结果未知分别表示；用户回答和关窗不作为资金事实。未知先查询/核查，按接口幂等键与重试策略执行；重复点击不重复建单、采购或退款。

支付、交付、通知分别有权威对象。继续支付重验当前订单和资格；取消不放行；查询未付不变已付；发码中不生成可复制假码。模拟可选择成功/失败/未知，但注入情景与真实外部验证分开记录。

验收：取消、回跳但未付、晚到成功、重复回调、请求超时、已退款后重试通知、不同账号恢复同一订单。PC立即出码及弹层内不再切支付方式是项目约定。归口：STD-ACT-001；client10.6；web11.5；04/05。

## P11 业务状态、展示标签和允许动作

适用：订单/交付/售后、待办角标、状态快捷入口。来源X02/X13。

候选条款：底层业务状态保持独立，展示页签/标签由明确函数映射；列表、数量、角标、详情与允许动作共享该映射。显示“处理中”不自动把业务推进处理中。不同端可用不同业务文案，但必须保留同义/不同义关系及取值来源。

中文交付以中文主显示，英文码作内部标识；未知/失效/会话失效分别呈现。相同“关闭”文字若代表未支付失效与交付完成两种意义，必须拆开底层枚举并说明展示映射，不能靠翻译表强行统一。

验收：相同订单跨列表/详情/快捷入口计数与按钮一致；未支付/已付未交付/已交付/退款/未知逐个断言。后台“已关闭/已完成”属于待确认项目语义。归口：workflow6；core3.4；client10.7/10.9；admin12.5。

## P12 已提交查询上下文

适用：后台筛选、页签、统计/导出与列表。来源X15/X18/X19。

候选条款：输入草稿和已提交查询快照分开。查询、刷新、重置、页签、翻页逐一规定对条件/页码/选中/抽屉/请求的影响。高级区折叠不默默清条件；日期声明时区、起止包含关系和范围校验。

列表、总数、页签数、指标、批量/导出声明各自集合及是否随筛选；有不同集合须明确告知，不能借共用样式暗示同口径。统计公式、金额单位与时间字段显式登记，模拟值同样需自洽或标明占位。

验收：改条件未查询、提交、换页签、刷新、失败恢复、重置；核对列表与计数/导出相同ID集合。归口：admin12.4/12.5/12.8；runtime13.2/13.5。

## P13 异步请求隔离

适用：查询、保存、上传、外部返回及延时任务。来源X16。

候选条款：发起时捕获不可变请求版本、目标对象/页面、条件快照与情景；响应仅提交给仍有效的目标版本。离页/切对象/重置后旧回调按契约取消或隔离；不得回调时重新读全局当前页决定写谁。

加载/成功/失败/未知应由动作状态消费到画面，不只存变量；旧请求不得提前结束新请求的loading。评审注入状态与真实业务请求状态分别建模。

验收：A请求慢B请求快、切页面后旧回调到达、重置后回调、两对象并发、超时后迟到成功。归口：runtime13.6；STD-RV-001。此为已有迟到响应规则的执行强化。

## P14 表格、分页、选择与指标

适用：后台工作列表及PC订单。来源X17～X19。

候选条款：主列按任务优先级选择，次要内容入详情；列声明格式/宽度策略/截断查看/空值/单位，行与操作携带稳定ID。当前对象失效展示明确提示，不退回第一条。分页支持当前页可识别、合法边界、数据缩减回退；不靠缩小字体塞列。

选择明确本页/跨页/全查询范围、全选/半选、翻页/筛选后的保留策略；批量执行前重验状态与权限，部分失败返回逐项结果。指标逐项定义集合，不能用固定模拟加值充当公式。

验收：0条/1条/末页/超过8页/删除末条；长ID与标题；隐藏选中项；混合合法/非法批量项；过滤后指标。归口：admin12.6～12.8、16.3；web11.6；STD-MODEL-002。

## P15 操作意图、副作用与任务交接

适用：查看、导出、领取/开始处理、确认完成、补发、退款。来源X25/X26。

候选条款：每个动作分别声明“读还是写、对象集合、权限、前置状态、确认内容、原子性、批次、结果/未知、补偿和审计”。查看默认不推进业务；若打开即领取，入口需明确表达领取，并定义冲突处理。导出文件/创建任务/改变业务状态是独立效果。

导出说明所选或全查询集合、字段/脱敏、文件/任务的实际产出。仅消息模拟需标明，不能宣告真实文件已可下载。导出是否领取任务按项目契约，永不等于交付完成；完成要有业务依据。

验收：只查看后退出不改状态、取消确认、混合状态批量、部分失败、重复执行、文件实际产出或明确模拟、后台动作前后前台一致。归口：admin12.7/12.8/12.10；STD-ACT-001；04/05。

## P16 权限、版本与不可变审计

适用：角色/菜单、查码、敏感操作、协议/模板发布。来源X27/X28。

候选条款：页面可见、动作允许、数据范围、敏感字段读取分层定义；动作执行前重新校验当前权限和对象。无权限反馈与空数据不同；原型模拟角色不等于服务端权限已实现。

写入前捕获旧值和版本，提交后记新值、操作者、对象、时间、操作/关联任务ID及结果；失败/未知按实际结果记。前后快照不可引用同一可变对象，不能用“旧值/新值”占位替代。日志敏感内容脱敏，审计不重写原交易/历史版本。

验收：有权限打开后撤权、数据越界、分配角色后核对真实before/after、版本更新后旧单可追溯、失败操作留痕。角色编辑/富文本范围由项目决定。归口：admin12.13；runtime13.3；05权限/留存。

## P17 图示分支、节点和可读性

适用：业务流程、状态机与时序图。来源X29。

候选条款：按语义选图，不按数量凑图。关键动作的成功、取消、明确失败、未知、重试/核查和终点可追溯；分支标条件，状态迁移说明事件与守卫，节点表和图源一致。检查未引用/不可达节点、缺出口决策及不合法回路。

未知与失败只有在后续处理完全相同且有依据时才可合并；涉及重复采购/支付/通知副作用时需保留核查边界。实际SVG尺寸缩放、文字可读、角色清楚和宽图策略遵循既有Q5/Q6，不强制全部画同一种方框。

验收：从购买入口逐条走取消/认证返回/取码未知/通知未知；核对每个终点与节点表；浏览器测实际缩放及宽图阅读。归口：[图示18章](../../../standards/diagrams-and-reader.md)；04/05。

## P18 横向语义一致与证据分层

适用：所有10项主交付物及辅助证据。来源X30。

候选条款：每次变更从组件/动作/业务字段定位原型、01、03、04、05、06、07、08、09的受影响项，逐项对照有效事实；不以文件内外同字节或十节齐全代替语义一致。组件共有规则可引用，实例差异须补齐，避免整页套通用正文。

验证分别记录结构、语法、隔离模型、浏览器入口、视觉/几何、外部联调；证据绑定当前哈希、夹具和步骤，原作者历史日志只作来源材料。声明端通过须覆盖该端主链，不能用APP成功代替PC。未执行状态明确保留。

验收：改一项规格价格、删除一个排序、变一次状态映射，检查所有受影响记录；点击原控件验证动作而非直接调用render。埋点按实际触发与去重核对，敏感信息不为追溯而扩大采集。归口：core3.4/3.5；quality26/27/29；STD-GATE-001。
