## C-01 按任务选弹层，不按业务名另造一套

**建议条款：** 项目只选用需求实际涉及的弹层类型；实例登记“类型、宿主、父层、对象 ID、标题、内容段、动作、尺寸档、关闭策略、状态与恢复目标”。不同业务共用同类型骨架；不得因文案不同复制一套宽度、间距和关闭逻辑。现有 PAT 编号保留，PAT-DRAWER-01/02 在本仓库指后台详情/编辑弹窗，不因名称含 DRAWER 强制做右侧抽屉。

| 类型及现有 PAT | UI 骨架与操作位置 | 适用范围与尺寸选型 | 关闭策略默认值 |
| --- | --- | --- | --- |
| 信息说明 / MODAL-01 | 标题、可选说明、正文、可选“知道了”、右上关闭 | 一次性信息；普通任务档，短信息按内容收窄，不人为撑高 | X、Esc、遮罩可关；内容区点击不能关闭或点穿 |
| 决策确认 / MODAL-03 | 动作标题、对象/影响、可选风险说明、取消＋明确动作名 | 短决策用确认档；不是复杂表单的容器 | 遮罩不可关；取消/X/Esc 均表示不执行；如业务禁关，逐项登记并保留可理解的出口 |
| 操作面板 / MODAL-02 | 上方标题/对象摘要、中间选择/输入、下方操作区 | 移动可底部面板；桌面可居中；长内容正文滚动 | 无修改直接关；已有修改走已登记的草稿策略；不能默认将关闭视为提交 |
| 后台只读详情 / DRAWER-01 | 固定标题栏：业务名＋对象标识＋按需动作＋末位 X；正文分组 | 普通任务档，确有复杂内容才用复杂档 | X、Esc、遮罩可关；返回原列表现场 |
| 后台编辑/配置 / DRAWER-02 | 固定标题栏：标题＋对象标识＋保存/提交＋末位 X；正文分组、行内错误 | 普通/复杂任务档；不额外复制底部保存栏 | 任何退出入口统一先检查脏数据；未修改直接关，已修改默认提示“放弃修改/继续编辑” |
| 子选择器 / 随父表单登记 | 子标题、查询/选项、草稿选择摘要、取消/确认；单项即时选用需明确说明 | 独立子层，尺寸受同一业务宿主限制；不借用其他项目的素材尺寸 | 取消不改父草稿；确认只回填父草稿；父层保留且仍被锁定 |
| 阅读/预览 / MODAL-01 或 READER-01、DGM-01 | 标题/关闭、阅读正文；按需目录、缩放、下载 | 业务阅读归业务宿主；评审工具归评审视口，不能混用 | 只读直接关；协议“关闭阅读”不等于同意；编辑器内预览不触发发布 |
| 外部流程结果查询 / ACTION-03、EXTERNAL-01 | 对象摘要、当前查询状态、明确下一步；按状态展示操作 | 已发起的外部任务与结果核实；不是确认即成功的弹窗 | 关闭查询层仅关闭展示；不推断外部任务已成功、失败或取消 |

“默认值”受现行生命周期权威和已批准业务覆盖约束。必须隐藏 X/禁用 Esc 的实例应登记原因、超时/失败恢复及替代出口，不能做无出口锁死层。

## C-02 弹层外观采用同一骨架和令牌

**建议条款：**

1. 内容面白底、1px 现行中性描边；普通业务控件/后台弹层沿用矩形。移动覆盖层可选 16px 圆角变体：居中四角圆，底部面板仅顶角圆；选定后同类复用。手机外框 22px 圆角不传给内部卡片和控件。
2. 遮罩建议统一为现行前景色叠加 45% 不透明度的独立令牌；不能把 opacity 加在包含正文的父层上。装饰阴影不作为默认必需项；不复制最终版 toast 阴影到所有弹窗。
3. 标题按组件标题层级 16～18px，正文 14px、辅助 12～13px。长标题允许换行或由完整标题的可达替代展示承接；不挤走关闭/主动作，也不把对象标识和标题连成不可读长串。
4. 弹层标题/正文/动作区分工固定：后台标题区与正文区建议内边距均为纵向 10px、横向 12px；移动面板正文建议 14px；动作间距 8px，段落/字段组按 L-01/L-03。此处 12/14px 是弹层变体专用值，不替换普通卡片内边距。
5. 短内容按内容高度呈现；长内容由正文独立滚动，标题、关闭和必要主操作持续可达。底部操作区不能压住最后一个字段、错误、键盘或安全区；不以整个弹层滚动带走关闭入口。
6. 桌面确认/普通/复杂最大宽建议分别为 400/600/920px；宽度是上限，不是强制拉满。最大高、宿主安全间距按 L-06：居中不超过宿主可用高 80%，底部面板 88%，两侧桌面至少 16px、移动至少 12px。边距和高度约束同时满足；后台不得使用整个 HTML 的 vh 冒充业务宿主高度。
7. 移动关闭按钮有效热区至少 44×44；后台随适用密度使用，视觉图标可小于热区。不得复制最终版 `.modal .x` 的 40px 当移动通过线，也不得用负外边距把两个命中区重叠。
8. 层级用“背景业务 < 当前层 < 子层 < 当前层反馈”的语义关系登记，不把源文件 5/70/88/90 当通用 z-index。反馈定位于所属业务宿主且不得挡住主动作或焦点；评审外壳反馈另行处理。

## C-03 所有出口显式映射到结果，避免只做打开效果

生命周期全部引用 [runtime 13.8 / STD-RT-001](../../../standards/runtime-and-build.md#138-滚动锁与嵌套滚动)，此处只补类型化出口表，避免建立第二套权威。

| 事件 | 必须写明的结果 | 不允许发生的隐式结果 |
| --- | --- | --- |
| 打开 | 绑定本次对象/上下文，初始化此对象草稿；加载前不展示另一对象的旧详情；焦点进入层 | 从记录 A 切记录 B 仍显示 A；打开即执行写操作 |
| 确认/保存 | 校验当前快照；提交中防重复；成功按实例更新父数据并按约定关闭/保留 | 仅 toast 成功，数据未变；保存失败也清空草稿 |
| 校验不通过 | 错误就地呈现，定位首个错误；层保留、值保留 | 只弹一次短提示；把错误写在画布外说明列 |
| 请求失败 | 保留草稿和对象，说明是否可重试；重试语义及参数明确 | 丢失输入；重试到别的对象；无限加载无出口 |
| 取消/X/Esc/遮罩 | 先按类型判定允许与否，再走同一脏数据/恢复逻辑 | X 直接丢弃但 Esc 绕过提示；遮罩点击穿到底层按钮 |
| 关闭子层 | 只处理子层结果；恢复父层焦点、草稿、滚动，父层背景继续锁定 | 同次 Esc 又关闭父层；子层取消后清空父表单 |
| 离开页面/换身份 | 使旧请求、计时器和回调失效；身份敏感数据按现行会话规则清理 | 关闭后旧保存回调打开旧弹窗；新身份沿用旧账号私有草稿 |
| 外部任务返回/超时 | 分开“已发起、处理中、明确结果、结果未知”；给查询/重试/返回路径 | 关闭支付查询框便把交易记成取消；唤起客服便记成联系成功 |

焦点循环、背景锁定、叠层事件消费、关闭后返回触发点按 STD-RT-001 验证；若触发点被删除或重绘，回到同一对象的有效入口或登记的安全位置，不仅保存一个已脱离 DOM 的节点引用。

## C-04 同类型弹层用一组代表数据和实际证据验证

**建议条款：** 每个实际选用的弹层模式至少登记一个可复用的测试夹具；实例差异只补对象、字段、动作和业务守卫。不要求项目实现全部模式，也不要求为每个相同弹窗复制完整用例。

| 夹具 | 操作序列 | 可观察断言 |
| --- | --- | --- |
| 短内容/长标题/长正文 | 打开并滚动到末尾；改变宿主宽高 | 居中或底部对齐的参照为业务宿主；无裁切；标题/关闭/主动作可达 |
| 编辑未保存 | 修改字段→分别尝试 X/Esc/允许的遮罩→继续编辑/放弃 | 所有出口同一策略；继续编辑保值，放弃后父数据不变 |
| 父编辑＋子选择＋确认 | 编辑父→开子→改子→取消/确认→再开子 | 父草稿/滚动不丢；取消不回填，确认只回填草稿；锁与焦点逐层恢复 |
| 保存失败/重复/迟到 | 连点保存→模拟失败→重试；另测关闭/换对象后迟到 | 同次只提交一次；失败保值；过期响应不污染新对象 |
| 外部结果未知 | 发起→关闭展示→返回查询→超时/明确结果 | 不以界面关闭推断业务终态；可继续核实 |

实际结果必须保存业务宿主矩形、层矩形、视口/缩放/状态、截图、操作轨迹与结果。CSS 声明和组件文档只作预期来源。本轮未执行这些浏览器场景。
