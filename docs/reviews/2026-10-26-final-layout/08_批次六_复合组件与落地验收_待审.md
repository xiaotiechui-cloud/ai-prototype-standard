## C-09 媒体和长内容兼顾稳定布局与操作恢复

**建议条款：**

| 模式 | UI 规则 | 交互/异常规则 | 最少验收 |
| --- | --- | --- | --- |
| 图片/视频画廊 / GALLERY-01 | 容器比例按变体固定；图片适配方式按内容完整性选择；缩略图、索引与主画面对应；视频有识别/控制入口 | 0/1/多项分别处理；无项给真实缺失状态，不伪造商品图；单项不显示无效前后箭头；切对象重置索引 | 缺图、加载失败、末张切换、视频停止/离开清理、长标题无挤压 |
| 自动轮播 / CAROUSEL-01 | 可见的当前项标记；操作区不压关键内容 | 只有多项且实例启用时自动轮播；hover/focus/隐藏时暂停；手动切换后按登记策略重新计时；销毁清理定时器 | 单图无无效指示器；暂停/恢复/反复进入不叠计时器；点击使用当前项对象 |
| 长文展开 / EXPAND-01 | 摘要、展开/收起动作明确；可访问全文；展开不盖住后续动作 | 收起恢复内容锚点，不把用户留在页面之外；展开状态按实例范围保留 | 超长中英文、表格/链接、字号放大、展开后滚动再收起 |
| 时间线 / TIMELINE-01 | 时间、事件、结果、操作者（有权限时）分层；同粒度对齐 | 顺序和同时间排序规则明确；无记录显示空态；缺时间/未知状态不伪造 | 0/1/多条、相同时间、长备注、敏感字段权限 |
| 倒计时 / COUNTDOWN-01 | 数值与单位稳定；不挤动相邻操作；临界/到期有可读文案 | 使用已确认可信时间来源；到期触发已登记状态/动作；离开清理；不能以客户端计时独立裁定交易状态 | 0/负值、时钟差、后台恢复、重复进入、到期与提交同时发生 |

画廊/轮播/折叠属于通用模式，商品图比例、广告位高度、视频来源、倒计时业务时长属于实例配置，不从最终版复制为跨项目必需值。

## C-10 复杂编辑使用“草稿—确认—保存”的边界

**建议条款：** 父编辑器持有本次对象草稿；子选择器、行内编辑、上传、排序只修改所属草稿，除非业务明确规定该动作立即生效。保存整个对象与立即执行的行操作在名称、提示和结果上区分，不展示与实际生效范围相反的文案。

| 组件场景 | UI 结构 | 交互与副作用边界 | 必验序列 |
| --- | --- | --- | --- |
| 依赖字段/动态分组 / INPUT-03、CHOICE | 分组标题、说明、字段与错误位置固定；按条件展示必需字段，不留无意义大空白 | 切换上游值按登记策略保留/清理下游草稿；隐藏字段是否参与校验/提交明确；重绘不打断输入 | 改上游→填下游→切回→保存；显示/校验/请求值一致 |
| 可重复行/规格等 / INPUT-03、TABLE | 行标签/字段/删除动作对齐，新增入口靠近所属列表；行稳定标识独立于位置 | 新增/删/改均限定当前行；取消父层不写保存态；跨行错误定位准确；不把最终版禁删规格推广成通用限制 | 新增2行→删第1行→编辑剩余行→失败重试，数据不串行 |
| 选择器/关联对象 | 搜索、候选列表、选中态/摘要、确认取消清楚；空/失败各有恢复 | 查询条件与选中草稿独立；候选刷新不能偷换选中 ID；取消父子层均有明确回滚范围 | 选A→搜索B→取消/确认→父草稿对比；再开不残留其他父对象选择 |
| 素材管理/上传 | 添加、预览、状态、删除、排序在同一区域；尺寸/格式/数量限制只按已确认需求展示 | 选择文件不等于上传成功；区分等待/上传中/成功/失败；删除/替换影响范围清楚；上传迟到不复活已删素材 | 非法类型/超限、失败重试、上传中删除/关闭、顺序变化后预览 ID 正确 |
| 手工拖拽排序 | 操作栏提供“排序”拖拽把手；拖起、落点、当前拖项清楚；不把整个行变成不可选中文本的把手 | 使用稳定 ID；只在已定义排序范围内移动；松手更新草稿或立即保存按实例说明；取消/失败可恢复；禁止态有原因 | 长按把手拖动→松手→保存/取消；筛选/分页/权限变化不会悄悄跨范围排序；键盘可达的等效移动入口按可访问性要求提供 |
| 富文本/协议编辑 | 工具栏、编辑区、预览、校验和保存/发布职责分开；长内容在容器内滚动 | 明确允许的格式；输出按允许规则处理；预览不保存/发布；新版本、历史快照与发布守卫只按业务需要启用 | 粘贴带格式/不支持标签、长文、空内容、取消/保存失败、历史内容不被本次草稿覆盖 |

此处“草稿”不等于所有系统都只能一次性整体保存。已有明确的即时保存/自动保存业务需登记完成判据、失败恢复、撤销能力及与父层取消的关系。自动保存不是从参考 UI 外观推导出的默认能力。

## C-11 轻反馈、复制、外部交接与阅读工具各守职责

**建议条款：**

- 行内提示 / NOTICE-01：放在相关字段或任务前后，说明原因和下一步；关键约束常驻可读，不能只靠 hover 或瞬时 toast。错误/警告不只用颜色区分。
- 业务 toast：位于业务宿主内，不跑到整个 HTML 页顶；成功/失败文案指向实际动作；建议普通成功提示约 3 秒自动消失，确需长读/操作的信息改用行内区域或可关闭通知。错误唯一出口不得自动消失。`role=status` 等语义反馈与可见文案保持一致；计时器随所属页面清理，连续反馈不遮住主动作。
- 复制 / COPY-01：复制值与可见值的范围明确，脱敏值不能无授权变成明文；仅在剪贴板写入确认后提示成功；失败提供可选中复制的替代路径。长文本、权限拒绝、不同对象连续复制均验。
- 外部交接 / EXTERNAL-01：文案区分“准备跳转/已尝试唤起/已返回/结果已核实”；不具备能力时给可操作替代入口。返回恢复原上下文；携带参数仅限已批准范围，不把商城客服/支付能力强制带入其他项目。
- 评审阅读器 / READER-01：标题、目录、正文、切换/下载/关闭为工具结构；切换文档的滚动策略明确，全文可达，下载内容与所选文档一致。评审注释与组件编号不混入业务正文。
- 图示查看器 / DGM-01：缩放、还原、滚动、可选图源、关闭各自有效；按该工具契约恢复缩放/滚动，关闭后恢复评审入口。图源展开不能把业务画布撑高，也不能代替实际图示渲染成功的证据。

toast 的 3 秒是本轮建议默认值，来自最终版意图，不是无障碍阅读上限。需要用户作决定的内容不能改成 3 秒消失提示。

## C-12 交付组件的可解析契约和验收入口

**建议条款：** 在现有 03 十节结构内落实，不新建第二份必交组件文档。共享组件给出默认值，实例覆盖按“字段、旧值、新值、依据”登记；交付解析结果必须完整，不能只有“同共享组件”。

| 既有节 | 本轮补清的可验字段 |
| --- | --- |
| 名称/归属 | 稳定实例 ID、现有 PAT、适用端/密度、宿主/父层、职责及不适用项 |
| 数据来源 | 稳定对象键、草稿/提交/展示值、未知/空值、权限与敏感字段 |
| 交互逻辑 | 触发、守卫、实际副作用、范围、提交快照、去重、取消/恢复 |
| 反馈 | 适用状态、可见文案、动作可用性、错误位置、恢复入口 |
| 样式 | 变体/令牌、结构分区、字号/行高、边框/圆角、尺寸/热区、对齐/间距、滚动/固定区；目标与实测分开 |
| 状态变更 | 来源态→事件/守卫→目标态；异步迟到、换对象/身份、离开销毁等适用转换 |
| 接口/日志 | 真实结果与模拟结果区别；字段与既有接口/事件引用；不为通用组件虚构采集 |
| 测试/待确认 | 预期、夹具、关联 TC、证据定位与未执行；未确认行为及影响范围 |

### 跨组件连续验收夹具（计划）

1. **查询—详情—返回：** 提交条件→排序/翻页→点对象B→关闭详情；应保留条件/页码/滚动，始终为B。另测B不可访问不能显示A。
2. **编辑—子层—失败—重试：** 改父字段→子层选项确认→保存失败→继续改值→重试成功；草稿不丢、父子锁正确、数据与反馈一致。
3. **排序—编辑—取消：** 用把手排序→编辑被移动对象→取消；对象键不随行号改变；保存/取消范围与文案一致。
4. **加载—新查询—旧响应：** A请求未完成时提交B（若实例禁止并发，使用重置/重开等允许入口）；让A最后返回；只显示B结果，计数/页签/选择无旧值污染。
5. **外部交接—结果未知—返回：** 关闭外部结果展示后返回任务；没有伪终态，查询/恢复可用。
6. **尺寸与状态：** 在批准的手机内业务区、PC及后台代表工作区，测短/长内容、加载/空/失败/禁用和弹层；固定区不挡末项，热区/焦点实际可用。不能用 CSS 数值代替矩形与点击证据。

每项记录输入基线、适用组件/页面/状态、视口/容器/缩放、数据夹具、操作轨迹、实际结果、截图/日志和 DEF/DEC。共享夹具可复用，但每个实际存在差异的实例应补差异证据；结构扫描不能自动判语义/交互通过。
