# 购买弹层滚动问题修复记录

## 问题与原因

移动端从商品详情点击“立即购买”后，购买面板显示，但评审页面无法继续向下滚动到面板底部的“购买并支付”按钮。购买面板本身已有独立滚动区；实际原因是 `afterRender()` 在弹层打开时给整个 HTML 文档的 `body` 添加 `modal-open`，而 CSS 将其设为 `overflow:hidden`。原型画布低于浏览器视口时，评审页面因此无法滚动。

## 修复

- 移除全局 `body.modal-open` 滚动锁及其无用 CSS 规则。
- 保留弹层自身覆盖原型画布、面板正文独立滚动、底部主操作固定的布局。
- 未调整购买业务校验及原型尺寸。

定位：`02_低保真交互原型.html` 中 `afterRender()`（原约 1010 行）及原约 415 行全局 CSS。

## 修复后验证

使用 Edge + Playwright，视口 1440×900，从评审控件切换到 `M-PRODUCT-01`，实际点击“立即购买”：

- 评审文档高度 1421px，大于 900px 视口；弹层打开时 `body` 未锁定。
- 购买面板正文 `scrollHeight=638px`、`clientHeight=395px`，内部可滚动。
- 外层页面可滚至 `scrollY=521`，使底部购买操作进入视口。
- 点击“购买并支付”后进入 `M-BUY-01 / NOTICE`，显示“购买须知”弹层；无页面脚本错误。

这是针对本次修改版本的本地浏览器验证，不构成独立验收。
