# 内容与导航：执行细节

按 ui 7.4/15.2/15.6，先固定角色顺序、最小可读宽、预算与收拢条件，再用长内容/完整动作验证；导航/页签/筛选职责分开。媒体准备 0/1/多项及失败、长文全文/收起锚点、轮播暂停/重计时/清理、时间线未知与可信倒计时；不推广商城比例或时长。结果核对数据与当前稳定对象，图示须实际渲染/缩放，复制/下载须核对产物；适用连续路径见[动作矩阵](../acceptance/actions-and-results.md)。

读取 [模式入口](README.md)；权威为 [client10](../../standards/profiles/client.md#s-10)、[web11](../../standards/profiles/desktop-web.md#s-11)、[ui15](../../standards/ui-and-components.md#s-15)、[reader18/19](../../standards/diagrams-and-reader.md#s-18)。本文件不是已执行结果。

| 能力 | 实现前填写的契约 | 真实入口回归 |
| --- | --- | --- |
| 页面/导航 | 引用workflow6.7、ui15.2和docs-ui21.5；从任务确定层级、跨区分工和设计假设；分别登记可达/指定位置/批准架构、语义组及例外 | 同端/角色/状态/视口逐组比较实际目标、参数、条件、结果及返回；精简后核对覆盖、直达、权限和内容空间 |
| 搜索与历史 | 输入草稿、提交关键词、结果快照、历史去重/置顶/上限/删除/清空、空历史、返回策略 | 提交重复/不同词、删一条/清空、进入详情再返回；默认页不回填，项目覆盖另记 |
| 结果集 | 查询来源、空/失败/末页、追加去重、滚动及重试范围 | 无匹配不补演示商品；下一页失败保留已有结果，重试沿用条件 |
| 内容详情 | 信息分区/顺序、媒体序列、购买等主任务区、可选空块、窄/矮布局 | 长文/空字段、0/1/多媒体；缩略切换真实更新当前媒体，不改购买选择 |
| 客服与返回 | 当前对象ID、来源、可恢复条件、备用入口 | B订单携带B，公共入口不随机带旧单；唤起失败仍有可操作路径 |
| 阅读器/图示 | 文档历史/滚动/目录/下载目标，图的角色/节点/分支及缩放 | A中段→B→返回恢复A；下载核对内容；逐分支阅读、实测SVG缩放 |

搜索历史和默认页不回填属于既有要求；涉及搜索且无明确覆盖时执行，条数/长度按已定义契约，不能把商城示例值当所有项目默认。详情分区由页面任务决定，商城左媒体/右购买布局只适用于项目契约。

空值/缺失/未取得/失败按[business24.5](../../standards/deliverables-business.md#s-24)选夹具；返回与同对象重开按[runtime13.5](../../standards/runtime-and-build.md#s-13)登记策略，实际检查关键词、页码、选择与位置，不只核对pageId。

按 [quality29](../../standards/quality-and-evidence.md#s-29) 记录真实点击、数据/上下文前后、长内容截图与实际画布尺寸；原型模拟不证明外部客服、视频源或图示语义已获得业务批准。

## 入口分工的通用边界示例（非项目实测）

| 情形 | 按权威条款的检查重点 |
| --- | --- |
| 需求只要求能力有入口 | 现有路径是否满足；有无另外的位置/直达要求 |
| 多个区域各放完整清单 | 重做区域分工；逐项核对叠加的额外任务收益 |
| 同目标携带当前对象 | 实际对象/参数、权限、结果与返回是否不同且有收益 |
| 长页首尾关键操作 | 对同一当前对象生效、重复提交防护及反馈是否正确 |
| 参考区域的功能不适用 | 不补位引入新功能；区域本身若为明确要求须先裁决 |
| 文档与原型一致 | 仍从PRD和批准决定核对，不让共同推断自证正确 |

上述例子不规定菜单或数量，不自动判例外通过；检查结果回填项目08。
