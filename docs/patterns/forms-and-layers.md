# 表单与层级：执行细节

读取 [模式入口](README.md)；权威为 [runtime13](../../standards/runtime-and-build.md#s-13)、[ui15.3/15.5](../../standards/ui-and-components.md#s-15)、[admin12](../../standards/profiles/admin.md#s-12)。本文件不新增项目字段或外部能力。

| 能力 | 契约要点 | 真实入口与不变断言 |
| --- | --- | --- |
| 依赖表单 | 字段来源/单位、规格与价格/限制、交付方式与必填项、草稿/提交边界 | 切规格/方式、非法输入、失败保存；金额与当前规格一致，失败不丢草稿 |
| 重复字段组 | 稳定子项ID、增删/最少项、校验归属、序号与数据身份区分 | 新增/删除/重排后编辑仍命中原子项，不按新位置写错对象 |
| 父子弹层 | 每层宿主、父层/触发入口、尺寸/滚动、允许出口、草稿与返回目标 | 主面板→帮助/协议/选择子层→取消/Esc；只退一层，父草稿/选择保留，背景仍锁 |
| 关联选择 | 候选查询、当前选择、确认才应用、失效与重复策略 | 选B后取消不改父值；确认B后保留B身份，对象失效报错不换成A |
| 素材管理 | 稳定媒体ID、顺序、预览对象、类型/大小依据、删除后回退 | 文件选择/取消/重选、拖排、删除当前/末项、保存重开；原生入口与注入夹具分开记录 |

关闭生命周期统一引用`STD-RT-001`，不在本文件另设默认。业务弹层依业务画布宿主，阅读器/图示依评审视口；测量实际剩余宽高，短视口可到达关闭和主操作。隐藏滑块后滚动仍可用。

字段生产消费与快照边界按[core3.4](../../standards/core.md#s-3)；使用B对象/非等差价格、重排后编辑及历史快照夹具验证。生效方式按[admin12.11](../../standards/profiles/admin.md#s-12)，不把首页草稿模式套到直接保存或无草稿协议发布。

表单输入沿[business24.5](../../standards/deliverables-business.md#s-24)记录原始类型、枚举解码和非法值处置；`"0"`/`"false"`是否等价由字段契约声明。父子层或批量表单按[core3.4](../../standards/core.md#s-3)固定成员身份与聚合条件，单成员完成不得直接代表父级全部完成。

查看、预览、取消不写业务事实；保留草稿不能被解释为保留资格校验通过。仅内存媒体预览说明边界，不宣称服务端上传/持久化。按 [quality29](../../standards/quality-and-evidence.md#s-29) 测截图、几何、命中与父子层前后数据，不以一张弹窗截图证明全部出口。
