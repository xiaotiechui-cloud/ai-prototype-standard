| 能力 | 契约要点 | 回归夹具与断言 |
| --- | --- | --- |
| 查询上下文 | 草稿/已提交、输入或选择是否即时查询、页签/高级筛选、刷新/重置/返回策略 | 填写不提交、Enter提交、折叠展开、切页签；结果/计数取同一已提交集合 |
| 请求隔离 | 页面/端/对象/请求版本、loading归属、超时/未知、离页失效 | 慢A快B、离页后A返回、关闭/重置；旧回调不写当前页、不结束B的loading |
| 列表/分页/选择 | 列预算与详情、唯一ID、当前页/跨页范围、空/末页恢复、半选 | 空/单条/多页，后页删除末项、选择后筛选；详情/复制B不能取A |
| 统计/导出 | 列表/页签/指标/导出各自集合、时间字段、公式/单位 | 同一输入比对结果；全局指标明确标识，不伪装成筛选结果 |
| 交付语义一致 | UI、01/03状态/字段、04/05规则、客户端06、07预期、08证据、09决策 | 改字段/规格/状态后按依赖横查；字节同源不等于含义已正确 |

表格超过7列不自动失败，按12.6登记依据并实测；无横向拖动/不裁切等端规则继续有效。不同ID、长字段、窄/矮容器及乱序夹具用来暴露问题，不能只给一页完全相同的样例行。

相同处理器仍需验证端与参数差异，单端通过不代表多端通过。失败由AI修复并回归受影响依赖，旧通过不直接继承到新哈希；执行状态与计数归08同源记录。
